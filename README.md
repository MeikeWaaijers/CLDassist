Welcome to the `CLDassist` package! This R package can be used to develop a Causal Loop Diagram (CLD) from scratch with the assistance of a Large Language Model (LLM). Follow the installation steps provided below to install `CLDassist` from this GitHub repository. Once installed, you can start exploring its features.

The functions in `CLDassist` and their output should be approached with caution. Depending on the specific LLM used, there may be financial implications. Furthermore, we want to emphasize that the answers generated by an LLM should not be taken as absolute truth.


## How to Use CLDassist

#### Install CLDassist

```{r eval=FALSE}
if(!require("remotes")) {
  install.packages("remotes", dependencies = T)
}

remotes::install_github("MeikeWaaijers/CLDassist")

library(CLDassist)
```

#### Quick Tryout

To quickly understand the capabilities of CLDassist, you can use the `cld()` function to generate a CLD. This function uses `causal_relation()`, `causal_direction()`, `causal_sign()` and `cld_plot()` functions included in `CLDassist` with default settings. For greater control and access to additional output, it's recommended to use these functions individually.

Access the help file for further instructions.

```{r eval=FALSE}
?cld
```

#### Individual Function Use

To create a CLD from scratch, the functions in this R package should be used in the following order:

`var_list()` --\> `causal_relation()` --\> `causal_direction()` --\> `causal_sign()` --\> `cld_plot()` --\> `search_literature()`

Access help files for specific functions as needed.

```{r eval=FALSE}
?var_list
?causal_relation
?causal_direction
?causal_sign
?cld_plot
?search_literature
```

#### Choosing a Large Language Model (LLM)

By default, `CLDassist` uses OpenAI's `gpt-4o`. Other built-in OpenAI models are `"gpt-4"`, `"gpt-4-turbo"` and `"gpt-3.5-turbo"`. In addition, any model from a supported provider can be used by writing it as `"<provider>/<model name>"` in the `LLM_model` argument. The supported providers are `openai`, `deepseek`, `together` and `huggingface`. Via Hugging Face, many open-weight models can be used with a single Hugging Face token, for example:

```{r eval=FALSE}
rel <- causal_relation(topic = "addiction",
                       variable_list = vars$final_list,
                       LLM_model = "huggingface/meta-llama/Llama-3.3-70B-Instruct")
```

For Hugging Face, the company that runs the model can be fixed by adding it after a colon (e.g. `"huggingface/moonshotai/Kimi-K2.6:coreweave"`). The same model can give slightly different results at different companies, so fixing the company makes results reproducible.

`CLDassist` reads the probability of each answer from the log probabilities of the model's first answer token. A model can therefore only be used if it returns log probabilities (including alternative tokens) and gives its answer directly, without "thinking" first. Reasoning models (e.g. GPT-5 and later OpenAI models) do not meet these requirements. Use `check_llm()` to check whether a model can be used:

```{r eval=FALSE}
check_llm("huggingface/moonshotai/Kimi-K2.6:coreweave")
```

The first time a provider is used, `CLDassist` asks for its API key and stores it for later use. Keys can be created at:

- OpenAI: <https://platform.openai.com/api-keys>
- DeepSeek: <https://platform.deepseek.com/api_keys>
- Together AI: <https://api.together.xyz/settings/api-keys>
- Hugging Face: <https://huggingface.co/settings/tokens>
